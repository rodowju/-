# 소프트런치 계획

> 목표: 재미/난이도/수익화 가설을 **실제 데이터**로 검증하고, 모델 기반 임시값(par 계수, Assist, 가격)을 교체한다.

## 1. 측정 지표 ↔ 이벤트 (GDD §11)
| KPI (가설 목표) | 계산 | 이벤트 |
|---|---|---|
| 첫 세션 5스테이지 도달 ≥ 60% | 설치별 첫 `session` 내 `stage_clear.stage ≥ 4` 비율 | `session_start`, `stage_clear` |
| 평균 세션 길이 3–5분 | 세션별 첫~마지막 이벤트 간격 | 모든 이벤트의 `ts` |
| D1 ≥ 30% / D7 ≥ 8% | 설치 ID별 `session_start` 날짜 | `session_start` |
| 탈락 후 즉시 재도전율 ≥ 70% | `stage_fail` 직후 10초 내 `stage_start` | `stage_fail`, `stage_start` |

위 수치는 **근거 있는 벤치마크가 아닌 임시 목표**다. 데이터가 쌓이면 재설정한다.

## 2. 튜닝 대상과 필요한 데이터
| 가설 값 | 현재 | 교체 방법 |
|---|---|---|
| par 계수 (`PAR_PCT`) | 인간형 모델 기반 | 스테이지별 `stage_clear.ticks` 분포의 백분위(★2 목표율)로 산출 |
| ★3 콤보 목표 | 2/3/4/5 | `maxMult` 분포로 조정 |
| Assist 규칙 | −1 / +1 tick | `stage_fail.cause`, `lateMs` 분포, Assist별 클리어율 |
| 난이도 곡선 (turn 경고 단축) | 300→200 ms | 스테이지별 실패율, 이탈(마지막 `stage_start` 스테이지) |
| 목숨 3개 | 고정 | `stage_out` 빈도 (너무 드물면 의미 없음) |
| 코인/스킨 가격 | 가설 | `purchase`, 코인 잔액 분포 |
| 광고 노출 | 정책 고정 | `ad_request/complete` 와 광고 직후 이탈 |

핵심 질문: **"생존은 쉽다"는 모델 결과가 실제로도 맞는가.** `stage_fail` 비율이 낮다면 난이도 축을 순위/★에 두는 설계가 유효하고, 높다면 경고 시간·Assist를 완화해야 한다.

## 3. 실기기 테스트 매트릭스 (최소)
| 구분 | 대상 |
|---|---|
| iOS | Safari (최신, 최신-1), 홈 화면 추가(standalone) |
| Android | Chrome (고/중/저사양 각 1대 이상), 삼성 인터넷 |
| 확인 | 60fps 유지(`perf.p95`), 입력 지연 체감, 오디오 재생 시작(첫 터치), 노치/제스처 영역, 가로 전환 시 동작 |

`perf` 이벤트(스테이지당 프레임 간격 p50/p95/max)로 기기별 성능을 수집한다.

## 4. 법무/정책 체크리스트 (출시 전 필수 · 미검증)
- [ ] **상표/IP:** 최종 게임명 상표 검색. 원작 명칭/캐릭터/의상/음악/대사 미사용 재확인.
- [ ] **개인정보/동의:** 현재 통계는 기본 허용(상점에서 끌 수 있음). EU/영국(GDPR), 캘리포니아(CCPA) 등 지역별 사전 동의 흐름 필요 여부 검토. 개인정보처리방침 작성.
- [ ] **아동:** 타깃 연령 결정. COPPA/아동 대상 광고 제한 검토. 연령 등급(IARC 등).
- [ ] **광고:** 선택한 네트워크의 콘텐츠 정책(폭력성 표현 수위), 동의 관리(CMP) 요구.
- [ ] **결제:** IAP(광고 제거) 도입 시 결제 사업자 정책.
- [ ] **지역별 규제:** 확률형 아이템 없음(현재 구조상 해당 없음), 지역별 사행성 규정 재확인.

## 5. 단계
1. 프리뷰 배포 → 지인 20~50명 플레이테스트 (실기기 매트릭스 확인)
2. 통계 수집기 연결 → 소규모 소프트런치(1~2개 지역)
3. 2주 단위로 KPI 점검 → par/Assist/난이도/가격 교체
4. 광고 SDK 연동 및 정책 검토 → 글로벌 확대 여부 결정
5. 멀티플레이(M6)는 잔존율과 유저 풀 확인 후

## 6. 알려진 한계 (소프트런치 전 인지)
- 입력 지연 보정 옵션 미구현 (GDD 리스크). 실기기 지연 편차가 크면 우선순위를 올린다.
- 광고는 개발용 모의 구현이다.
- 아트/사운드는 그레이박스/합성음 수준이다.
